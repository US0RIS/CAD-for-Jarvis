# Canonical UI reference

The canonical ForgeCAD v2 desktop reference is the 1586 × 992 target screenshot supplied with the clean-sheet rebuild request on 2026-09-09.

The implementation contract derived from that image is captured in `../PRODUCT_SPEC.md`. The reference establishes the required visual composition: left local-copilot rail, top project toolbar, visible design-lineage strip, dominant photorealistic exploded assembly viewport, right real-component library with product imagery, and bottom dock with the embedded code workspace.

Do not substitute the appearance of the previous ForgeCAD prototype as a design reference. If a design choice conflicts with the target screenshot and this specification, the target screenshot/specification wins unless the change is explicitly approved as a product decision.

A repository copy of the full-resolution binary reference should be added through normal Git/LFS when the local development checkout is created; connector-based repository writes intentionally avoid transporting the multi-megabyte source PNG.
